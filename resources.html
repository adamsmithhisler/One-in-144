Builder Resources

Quick references for builders who want to move beyond straight builds and begin experimenting with kitbashing, dioramas, weathering, and lighting.

Build Guides

GUIDE 01

Kitbashing Basics

Start with compatible scales and test-fit parts before making permanent changes.

  • Compare proportions before combining parts.
  • Plan attachment points before cutting.
  • Make reversible changes whenever possible.
  • Use filler and sanding to blend modifications.

GUIDE 02

Diorama Planning

Build the environment around a clear focal point and keep the scene consistent with the model scale.

  • Choose the main subject first.
  • Keep terrain and structures in scale.
  • Use foreground and background elements.
  • Avoid overcrowding the scene.

GUIDE 03

Weathering Basics

Weathering works best when effects are added in light layers instead of all at once.

  • Start with panel lines and subtle washes.
  • Add wear where movement would naturally occur.
  • Keep dirt and damage consistent with the setting.
  • Build effects gradually.

GUIDE 04

Lighting a Build

Plan LEDs and wiring before final assembly so the electronics can be hidden inside the model or base.

  • Plan wire routes before assembly.
  • Test LEDs before sealing components.
  • Leave access for batteries or power connections.
  • Use lighting to support the scene instead of overpowering it.
